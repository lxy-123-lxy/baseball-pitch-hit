# 棒球投打 · 本垒对决

原创的单人投打网页游戏。手机与电脑打开就能玩，无需账号、服务器、构建或第三方素材。

- 6 球练习：2 快、2 慢、2 混合（恰好一颗坏球）。
- 标准对局：两轮共 24 球，每 6 球换边，玩家先打。选球种、落点再发球，每个投手每组最多投一个坏球。
- 按下「挥棒」或空格。好球甜区 2 分、普通命中 1 分，坏球放过 1 分。快球 650 ms、慢球 950 ms。甜区 ±45 ms、普通命中 ±110 ms，过板 150 ms 后截止。

## 本地启动

```sh
python3 -m http.server 8000
```

打开 http://127.0.0.1:8000/ 。`?rounds=1&seed=42` 可固定种子并开启 12 球短局，默认不固定种子。脚本使用原生模块与相对路径。仅在本机保存音效偏好，不收集数据。

`rules.js` 包含逐球配置、计分、数据模型和 AI；`field.js` 绘制球场；`app.js` 处理时钟、界面、输入和音效。GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 禁用 Jekyll。Node 规则测试可在项目目录运行 `npm test`。
